# Poradniki Publisher

Poradniki Publisher is a personal, single-user tool. Its owner uses it to upload videos to his own YouTube channels and to read the statistics of those channels.

## What it does

It uploads videos, thumbnails and captions to the owner's YouTube channels. It sets the titles, descriptions and publish times of those videos. It reads channel and video statistics and comments, and posts the channel's replies.

## Who can use it

Only the owner of the tool. It is not offered to the public and has no sign-up.

## Google user data

The tool uses the YouTube Data API and the YouTube Analytics API with the owner's own Google account. See the [Privacy Policy](privacy.html).
